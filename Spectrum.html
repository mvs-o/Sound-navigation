📝 Как использовать

  • Левая панель - мгновенная частотная характеристика (спектр) звука
  • Правая панель - спектрограмма: изменение частот во времени (новые данные справа)
  • Используйте ползунок для изменения длительности истории на спектрограмме (5-60 секунд)
  • Выберите цветовую схему для спектрограммы (теплая, холодная, радужная)
  • Нажмите "Запуск анализа" для начала захвата звука с микрофона
  • Нажмите "Остановить" для прекращения захвата звука
  • Нажмите "Очистить" для сброса графиков и показателей
⚠️ Для работы приложения необходим доступ к микрофона. Браузер запросит разрешение при первом запуске. Спектрограмма показывает, как частоты меняются со временем: низкие частоты внизу, высокие - вверху.
